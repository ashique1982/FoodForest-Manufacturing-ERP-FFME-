# ১. Purpose

Upazila Module-এর উদ্দেশ্য হলো একটি District-এর অধীন প্রশাসনিক অঞ্চল (Sub-District / Upazila / Thana / Taluk / Township) একটি Standard Master Data হিসেবে পরিচালনা করা।

এই Module Address Management, Territory, Route Planning, Sales Coverage, Customer Management, Distributor Management এবং Field Operations-এর ভিত্তি হিসেবে কাজ করবে।

---

# ২. Definition

Upazila হলো District-এর অধীন একটি প্রশাসনিক অঞ্চল।

বিভিন্ন দেশে এর নাম ভিন্ন হতে পারে।

| Country    | Administrative Name                               |
| ---------- | ------------------------------------------------- |
| Bangladesh | Upazila / Thana                                   |
| India      | Taluk / Tehsil / Block                            |
| Pakistan   | Tehsil                                            |
| Nepal      | Municipality / Rural Municipality                 |
| Malaysia   | District Office Area (Country Structure অনুযায়ী) |

FFME-তে এদের সবাইকে একটি সাধারণ কাঠামোতে **Upazila** হিসেবে সংরক্ষণ করা হবে।

# ১৩. Business Rules

### Rule 001

প্রতিটি Upazila অবশ্যই একটি District-এর অধীনে থাকবে।

---

### Rule 002

একই District-এর মধ্যে Upazila Name Unique হবে।

---

### Rule 003

Upazila Delete করা যাবে না।

Inactive করা যাবে।

---

### Rule 004

Route এবং Upazila আলাদা Master হবে।

---

### Rule 005

Address Master-এ Upazila বাধ্যতামূলক হতে পারে (Company Policy অনুযায়ী)।

---

### Rule 006

Upazila একটি Shared Master Data।
