# ১. Purpose

Mobile Banking Module-এর উদ্দেশ্য হলো FFME ERP-তে Mobile Financial Services (MFS) যেমন bKash, Nagad, Rocket, Upay ইত্যাদির মাধ্যমে অর্থ গ্রহণ (Collection), অর্থ প্রদান (Payment), Fund Transfer এবং Financial Reconciliation একটি Standard Framework-এর মাধ্যমে পরিচালনা করা।

এই Module Sales, Purchase, Finance, Collection, Expense, Payroll এবং Payment Module-এর সাথে সমন্বিতভাবে কাজ করবে।

---

# ২. Definition

Mobile Banking বা Mobile Financial Service (MFS) হলো মোবাইল নম্বরভিত্তিক ডিজিটাল আর্থিক সেবা, যার মাধ্যমে নগদ ছাড়াই অর্থ লেনদেন করা যায়।

FFME-তে Mobile Banking একটি **Digital Financial Account** হিসেবে বিবেচিত হবে।

# ১৭. Business Rules

### Rule 001

প্রতিটি Wallet একটি Provider-এর অধীনে থাকবে।

---

### Rule 002

Mobile Number Unique হবে।

---

### Rule 003

Inactive Wallet নতুন Transaction-এ ব্যবহার করা যাবে না।

---

### Rule 004

Transaction ID বাধ্যতামূলক হবে (যদি Provider প্রদান করে)।

---

### Rule 005

Refund মূল Wallet-এর মাধ্যমে করা উত্তম।

---

### Rule 006

Reconciled Transaction পরিবর্তন করা যাবে না।

# ২০. Notes

FFME Architecture-এ—

| Entity                  | Purpose            |
| ----------------------- | ------------------ |
| Mobile Banking Provider | সেবা প্রদানকারী    |
| Wallet                  | ডিজিটাল অ্যাকাউন্ট |
| Transaction             | অর্থ লেনদেন        |
| Collection              | অর্থ গ্রহণ         |
| Payment                 | অর্থ প্রদান        |

**Mobile Banking** এবং **Bank Account** আলাদা Entity।

* **Bank Account** = ব্যাংকের অ্যাকাউন্ট
* **Mobile Banking Wallet** = MFS Wallet

দুইটিই Financial Entity-এর অংশ এবং একই Accounting Framework-এ কাজ করবে।
