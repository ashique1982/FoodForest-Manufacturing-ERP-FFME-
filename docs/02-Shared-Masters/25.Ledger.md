# ১. Purpose

Ledger Module-এর উদ্দেশ্য হলো FFME ERP-এর সমস্ত আর্থিক লেনদেন (Financial Transactions) একটি Standard Chart of Accounts (COA)-এর মাধ্যমে শ্রেণিবদ্ধ, সংরক্ষণ এবং রিপোর্টিং করা।

Ledger Module Accounting, Sales, Purchase, Inventory, Manufacturing, HR, Payroll, Banking এবং Finance-এর মূল ভিত্তি।

---

# ২. Definition

Ledger হলো Accounting System-এর এমন একটি Account যেখানে নির্দিষ্ট ধরনের আর্থিক লেনদেন জমা (Post) হয়।

FFME-তে প্রতিটি Financial Transaction অবশ্যই একটি Ledger-এর সাথে সম্পর্কিত হবে।

Ledger একটি **Shared Financial Master**।

---

# ৩. Ledger Philosophy

FFME-তে—

* **Ledger** বলে **কোন Account-এ** টাকা যাবে।
* **Cost Center** বলে **কোথায়** টাকা খরচ বা আয় হয়েছে।
* **Journal** বলে **কিভাবে** Double Entry হবে।

# ১৪. Business Rules

### Rule 001

Ledger Code Unique হবে।

---

### Rule 002

Ledger Delete করা যাবে না।

Inactive করা যাবে।

---

### Rule 003

প্রতিটি Ledger একটি Ledger Group-এর অধীনে থাকবে।

---

### Rule 004

Financial Transaction অবশ্যই Ledger-এর মাধ্যমে Post হবে।

---

### Rule 005

Direct Ledger Balance পরিবর্তন করা যাবে না।

Journal Entry-এর মাধ্যমে পরিবর্তন হবে।

---

### Rule 006

Ledger Type পরিবর্তনের আগে Transaction History যাচাই করতে হবে।
