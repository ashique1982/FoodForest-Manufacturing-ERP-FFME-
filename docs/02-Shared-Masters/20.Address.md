# ১. Purpose

Address Module-এর উদ্দেশ্য হলো FFME ERP-তে সকল Entity-এর ঠিকানা (Address) একটি **Unified, Reusable এবং Standard Address Framework**-এর মাধ্যমে পরিচালনা করা।

এই Module ব্যবহার করবে—

* Company
* Branch
* Warehouse
* Customer
* Supplier
* Distributor
* Wholesaler
* Employee
* Vehicle Registration
* Asset Location

---

# ২. Definition

Address হলো কোনো ব্যক্তি, প্রতিষ্ঠান বা সম্পদের ভৌগোলিক অবস্থান (Physical Location)।

FFME-তে Address একটি **Shared Entity**, অর্থাৎ প্রতিটি Module নিজস্ব Address Table তৈরি করবে না; বরং একই Address Structure ব্যবহার করবে।

---
