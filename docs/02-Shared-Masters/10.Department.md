# ১. Purpose

Department Module-এর উদ্দেশ্য হলো FFME ERP-তে একটি প্রতিষ্ঠানের বিভিন্ন বিভাগ (Department) এবং তাদের কার্যক্রম, দায়িত্ব, কর্মী, বাজেট, সম্পদ এবং Performance একটি Standard Organizational Framework-এর মাধ্যমে পরিচালনা করা।

Department Module HR, Finance, Manufacturing, Sales, Purchase এবং Administration-এর সাথে সমন্বিতভাবে কাজ করবে।

---

# ২. Definition

Department হলো Company-এর একটি সাংগঠনিক (Organizational) ইউনিট, যার নির্দিষ্ট দায়িত্ব, জনবল এবং কাজের ক্ষেত্র থাকে।

Department কোনো Location নয় এবং কোনো Business Partner-ও নয়।

# ১৯. Notes

FFME Architecture-এ—

| Entity      | Purpose                |
| ----------- | ---------------------- |
| Department  | Organizational Unit    |
| Section     | Department Subdivision |
| Team        | Working Group          |
| Employee    | Human Resource         |
| Cost Center | Financial Analysis     |

Department এবং Branch একই বিষয় নয়।

* **Branch** = ভৌগোলিক/প্রশাসনিক ইউনিট
* **Department** = কার্যভিত্তিক (Functional) ইউনিট
