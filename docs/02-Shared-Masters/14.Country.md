# ১. Purpose

Country Module-এর উদ্দেশ্য হলো FFME ERP-তে সকল দেশের (Country) তথ্য একটি Standard Master Data হিসেবে সংরক্ষণ করা, যাতে Company ভবিষ্যতে Multi-Country Operation পরিচালনা করতে পারে।

এই Module Address, Currency, Tax, Language, Time Zone, Business Partner, Branch এবং Territory Module-এর ভিত্তি হিসেবে কাজ করবে।

---

# ২. Definition

Country হলো একটি সার্বভৌম রাষ্ট্র (Sovereign Nation), যার নিজস্ব—

* নাম
* ISO Code
* Currency
* Time Zone
* Tax System
* Administrative Structure

থাকে।

FFME-তে Country একটি **Shared Master Entity**।
