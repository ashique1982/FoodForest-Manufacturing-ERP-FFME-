# ১. Purpose

Division Module-এর উদ্দেশ্য হলো একটি দেশের প্রথম স্তরের প্রশাসনিক অঞ্চল (First Level Administrative Unit) একটি Standard Master Data হিসেবে পরিচালনা করা।

FFME-তে Division Module Address Management, Territory, Branch, Warehouse, Business Partner, Employee এবং Reporting-এর ভিত্তি হিসেবে কাজ করবে।

---

# ২. Definition

Division হলো একটি দেশের প্রথম স্তরের প্রশাসনিক অঞ্চল।

বিভিন্ন দেশে এর নাম ভিন্ন হতে পারে।

উদাহরণ:

| Country    | First Level Name |
| ---------- | ---------------- |
| Bangladesh | Division         |
| India      | State            |
| Pakistan   | Province         |
| USA        | State            |
| UAE        | Emirate          |
| Malaysia   | State            |

FFME-তে এদের সবাইকে একটি সাধারণ কাঠামোতে **Division** হিসেবে সংরক্ষণ করা হবে।

# ১৩. Business Rules

### Rule 001

প্রতিটি Division অবশ্যই একটি Country-এর অধীনে থাকবে।

---

### Rule 002

একই Country-এর মধ্যে Division Name Unique হবে।

---

### Rule 003

Division Delete করা যাবে না।

Inactive করা যাবে।

---

### Rule 004

Division পরিবর্তন করলে সংশ্লিষ্ট Address যাচাই করতে হবে।

---

### Rule 005

Division-এর অধীনে অন্তত একটি District থাকা উচিত (যদি Country Structure তা সমর্থন করে)।

---

### Rule 006

Division Master Shared Data হিসেবে ব্যবহৃত হবে।
