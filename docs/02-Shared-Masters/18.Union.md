# ১. Purpose

Union Module-এর উদ্দেশ্য হলো Upazila-এর অধীন সর্বনিম্ন প্রশাসনিক অঞ্চল (Union / Ward / Municipality Zone / Village Cluster) একটি Standard Master Data হিসেবে পরিচালনা করা।

এই Module Address Management, Customer Coverage, Distributor Coverage, Delivery Planning, Sales Coverage এবং Route Optimization-এর ভিত্তি হিসেবে কাজ করবে।

---

# ২. Definition

Union হলো একটি Upazila-এর অধীন স্থানীয় প্রশাসনিক ইউনিট।

বিভিন্ন দেশে এর সমতুল্য নাম ভিন্ন হতে পারে।

| Country           | Administrative Name       |
| ----------------- | ------------------------- |
| Bangladesh        | Union                     |
| Bangladesh (City) | Ward                      |
| India             | Gram Panchayat            |
| Pakistan          | Union Council             |
| Nepal             | Ward                      |
| Malaysia          | Local Administrative Area |

FFME-তে এদের সবাইকে একটি সাধারণ কাঠামোতে **Union** হিসেবে সংরক্ষণ করা হবে।

# ১২. Business Rules

### Rule 001

প্রতিটি Union অবশ্যই একটি Upazila-এর অধীনে থাকবে।

---

### Rule 002

একই Upazila-এর মধ্যে Union Name Unique হবে।

---

### Rule 003

Union Delete করা যাবে না।

Inactive করা যাবে।

---

### Rule 004

Union Master Shared Data হিসেবে ব্যবহৃত হবে।

---

### Rule 005

Customer Address-এ Union Company Policy অনুযায়ী Optional বা Mandatory হতে পারে।

---

### Rule 006

Union পরিবর্তন করলে Territory ও Route পুনরায় যাচাই করা উচিত।
